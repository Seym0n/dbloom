# 20 — Adapted legacy requirements in DBLoom wording

**Status: machine-drafted, not reviewed (2026-10-23).** Answer to the "ADAPT rows need DBLoom wording" point of `OPEN.md` item 1. The 343 legacy requirements that `18-scope-triage.md` marks ADAPT were rewritten by 10 Haiku subagents from the full legacy text and the triage note, as one or two sentences about the behaviour without the PHP realisation. The wording is a draft: it may drop detail, and numbers may be legacy limits. **UNSURE rows are not implementation requirements (owner, 2026-10-23):** they are not built and not tested; they stay in this file as a watch list, to be remembered and picked up if a later decision makes them apply. Rows with status UNSURE (45) need a decision before they can become requirements. The legacy ID stays the key until the rows get DBLoom IDs. Import and export rows name only SQL, CSV and JSON.
